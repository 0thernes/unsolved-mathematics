# Claims Ledger & Falsification Matrix (`CLAIMS.md`)

> **Build Standard v1.1.0 items B04 & B42.** Every substantive claim made in `unsolved-mathematics` is catalogued below with its epistemic tier, exact verification evidence, scope limitation, and explicit **what would prove us wrong** falsification condition.
>
> **Epistemic Tag Legend:**
> - `kernel-checked` — Mechanically verified by Lean 4.35.0 (`lean`, `leanchecker-paranoid`, `lean4lean`, `nanoda_bin`, `con-leche`, `con-ron`) with zero `sorry`, zero `admit`, zero `native_decide`, and axioms strictly within `{propext, Classical.choice, Quot.sound}`.
> - `machine-checked-ci` — Verified automatically on every push by deterministic Python scripts and test suites in CI.
> - `primary-source-verified` — Verified directly against live Crossref DOI and/or arXiv API metadata (`data/citation-verification-log.json`).
> - `computational-certificate` — Verified by exact integer/rational arithmetic or deterministic numerical scripts with bounded scope.
> - `editorial-synthesis` — Human/AI mathematical curation reflecting published consensus; inherently revisable.
> - `open-conjecture` — Unresolved mathematical problem; **no proof or disproof is claimed by this repository**.
