# The Riesel Problem

> **Atlas Rank #103** · CSS **55.267** · Field: *Number Theory* · Posed: **1956** · Status: `active-progress`

## Plain statement

A Riesel number is an odd positive integer k such that k * 2^n - 1 is composite for every integer n >= 1. Hans Riesel proved in 1956 that k = 509,203 is a Riesel number; the Riesel problem asks whether 509,203 is the smallest Riesel number (equivalently, whether every remaining odd candidate k < 509,203 produces at least one prime k * 2^n - 1).
