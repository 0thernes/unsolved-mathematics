# Attempts — The Riesel Problem

_Notable attempts, near-misses, retracted proofs._

- **Uncovered Covering-System Searches.** Systematic searches for covering systems covering any of the remaining 41 values of $k < 509{,}203$ have found none, reinforcing the heuristic consensus that $509{,}203$ is indeed minimal (just as $78{,}557$ is believed minimal in the sibling Sierpiński problem, which has only 5 remaining $k$ values).
- **PrimeGrid Milestone Eliminations.** Dozens of stubborn $k < 509{,}203$ values that resisted decades of testing eventually yielded multi-million-digit primes (e.g., $k = 107347, 162941, 229343, 273809, 304207, 40597$, etc.), demonstrating empirically that large prime-free dry spells up to $n > 10^7$ are consistent with probabilistic prime scarcity.
