# The Dirichlet Divisor Problem

> **Atlas Rank #10** · CSS **77.4** · Field: *Analytic Number Theory* · Posed: **1849** · Status: `active-progress`

## Plain statement

Let D(x) = sum_{n <= x} d(n) be the summatory divisor function and Delta(x) = D(x) - x log x - (2 gamma - 1) x be the error term. Determine the infimum theta of all exponents alpha such that Delta(x) = O(x^alpha); the Dirichlet divisor conjecture asserts that theta = 1/4 (i.e., Delta(x) = O_eps(x^{1/4 + eps}) for all eps > 0).
