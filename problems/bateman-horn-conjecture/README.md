# The Bateman–Horn Conjecture

> **Atlas Rank #17** · CSS **74.467** · Field: *Analytic Number Theory* · Posed: **1962** · Status: `open`

## Plain statement

Given distinct irreducible integer polynomials f_1, ..., f_k with positive leading coefficients whose product has no fixed prime divisor (Bunyakovsky/Schinzel admissibility), the number of integers n <= x for which f_1(n), ..., f_k(n) are all simultaneously prime is asymptotic to (C(f_1,...,f_k) / prod deg(f_i)) * integral_2^x dt / (log t)^k, where C is the explicit local Euler product.
