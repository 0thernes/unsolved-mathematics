## Link 1: Regeneration Sieve

### Core content

The first thread takes the repo's spine-ladder identity

```text
T^d(x) - rho_w = (3^o / 2^d)(x - rho_w)
```

and turns the regeneration seam into a block-transition normal form. If

```text
x - rho = 2^s u,  u odd in Z_2,
```

and `x` follows source word `w` for `k` full blocks, then for a target spine
`eta`,

```text
F_w^k(x) - eta = 2^(s-kd) u 3^(ko) + (rho - eta).
```

With

```text
a = s - kd
b = v2(rho - eta)
```

the valuation is forced to be `min(a,b)` unless `a == b`. In the matched case,
extra regeneration is equivalent to an odd-unit congruence:

```text
(3^o)^k == -C u^(-1) mod 2^e.
```

The thread's example is the transition from the `-1` spine to the `-5` spine:
deep regeneration for the pure Mersenne unit would require

```text
3^k == -1 mod 2^e,
```

which has no solution for `e >= 3` in the tested range because `-1` is not in
the subgroup generated by `3` modulo `2^e`.

### Verdict

Accepted as a theorem target. The identity is elementary algebra once the
spine-ladder lemma is accepted. It is not a proof. It is a precise way to say
"fresh alignment is rare only after a matching phase and odd-unit lock."

## Link 2: Phase-Collision Sprint

### Core content

The second thread correctly sharpens link 1. Regeneration is not merely
block-to-block; the sharper object is:

```text
source spine phase -> target spine
```

Let `rho_t = T^t(rho_w)` and let `a_w(t)` count odd symbols in the first `t`
symbols of the periodic source word. If

```text
x - rho_w = 2^m u,
```

then

```text
T^t(x) - eta = 3^a_w(t) 2^(m-t) u + (rho_t - eta).
```

Again, if

```text
m - t != v2(rho_t - eta),
```

then high cancellation is impossible. If equality holds, regeneration becomes
one exact odd-unit congruence modulo `2^R`.

The thread also reports an important negative result: the phase gate alone is
too weak. Its reported depth-12 phase library had about `70.5%` phase
eligibility under its counting convention. Local reproduction with explicit
primitive/nonprimitive denominators found:

```text
unique target spines:  0.777558620542
all target cycles:     0.751980433903
```

The exact value differs by convention, but the mathematical conclusion agrees:
phase mismatch alone cannot carry a proof.

### Positivity sensor

The thread introduces a positivity-sensitive inverse-residue statistic. For
the critical barrier word

```text
b_j = a_j - a_(j-1),  a_j = min c with 3^c >= 2^j,
```

compute the unique inverse residue `r_L mod 2^L` and

```text
P_L = min(r_L, 2^L - r_L).
```

For a fixed positive or negative integer matching an infinite parity word,
`P_L` would eventually be bounded. The critical boundary ray has large
nearest-integer distance:

```text
L=64:  bit length 63
L=128: bit length 123
L=256: bit length 255
L=512: bit length 509
```

This only says the canonical critical ray is not behaving like a fixed integer.
It does not exclude all bounded-height or perturbed boundary rays.

### Verdict

Accepted as the most useful of the four threads. It produced the current local
frontier:

```text
Collatz as a positivity-sensitive phase-collision and odd-unit-lock problem.
```

## Link 4: Round 21 Density / Boundary Package

### Core content

The thread attacks finite coefficient stopping:

```text
forall n > 1, exists j: 3^q_j(n) < 2^j.
```

Let

```text
a_j = min c with 3^c >= 2^j.
```

A length-`k` parity word survives the coefficient barrier if every prefix has
at least `a_i` ones. If `B(k)` is the number of such words, then `B(k)/2^k` is
the exact natural density of residue classes with coefficient stopping time
greater than `k`.

Since any survivor word has at least about

```text
alpha*k, alpha = log_3 2
```

ones, the binomial entropy bound gives

```text
B(k) / 2^k <= (k+1) 2^(-k(1 - H(alpha))).
```

Because

```text
H(log_3 2) ~= 0.949955527188331 < 1,
```

the infinite coefficient-barrier survivor set has natural density zero.

The thread also claims a boundary-ray audit through `k <= 200000`, with:

```text
first_drop_parent_lengths = 126186
failures = 0
weak_equalities = 1  # trivial k=1
smallest_positive_gap = 1 at k=3 c=2 eps=0
```

### Verdict

Partially accepted. The density-zero theorem is sound but weak: density zero
does not imply emptiness. The local lab reproduced the exact DP counts through

## Integrated Understanding

The four links form a coherent progression:

1. **Spine expulsion is exact.** The repo's spine-ladder identity tells us how
   alignment to a supercritical spine burns.
2. **Fresh regeneration is the wall.** After expulsion, new alignment to a
   later spine is a valuation of an explicit affine 2-adic expression.
3. **Phase matching is necessary but not sufficient.** Most source-target
   pairs still allow many phase residues; the proof cannot stop at phase.
4. **The real lock is odd-unit congruence.** Deep regeneration requires a
   specific residue of a power of `3` times the incoming odd unit.
5. **Density tools make the exceptional set tiny, not empty.** Round 21's
   density-zero firewall narrows the battlefield but cannot prove no positive
   integer lives inside the nested null set.
6. **Finite scans can raise floors but do not replace symbolic growth.** Round
   20, even if true, is still far below the next stated first-drop wall.

The actionable theorem target is now:

```text
Any positive orbit repeatedly riding supercritical cylinders must realize a
sequence of deep odd-unit locks. Prove the cumulative codimension of those
locks eventually dominates the entropy of admissible survivor branches, while
using positivity/finite binary support in a way parity-word statistics alone
cannot.
```
