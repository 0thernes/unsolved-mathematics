## Executive Verdict

The repo is not ahead of the field as a Collatz proof engine. Tao, Hercher,
Barina, Lagarias-style bibliography/survey work, and modern formal/computational
papers remain the public anchors.

The repo is unusually strong as a weirdness lab and failure-control system:

1. it keeps exact local objects instead of only prose;
2. it preserves failed proof shapes instead of burying them;
3. it uses sibling maps as adversarial controls;
4. it treats 2-adic ghosts as first-class inhabitants;
5. it separates measured, proved, heuristic, and quarantined claims;
6. it turns AI-produced breadth into claim manifests, falsifiers, and audits.

The most honest "1/1" candidate is not a theorem. It is the combined workflow:

```text
public literature wall
  + local exact frontier/spine/phase artifacts
  + sibling false-world detectors
  + retimed finite theorem mining
  + anti-pseudoproof quarantine
  + algorithm/tool triage
  = an adversarial Collatz research operating system
```

That is rare. It is not the same thing as being mathematically ahead of Tao or
Hercher. It is the correct platform for trying to find something genuinely new.

## The Bizarro Reframe

Stop seeing Collatz as a sequence problem.

See it as an interface problem between incompatible worlds:

```text
positive integers
  finite, ordered, archimedean, value-sensitive

2-adic full shift
  infinite, symbolic, parity-complete, ghost-rich

affine cocycle
  exact local update law, sign-sensitive translation, carry/regeneration engine

sibling universes
  same parity statistics, different truth behavior

proof systems
  finite certificates, formalizable lemmas, and seductive false abstractions
```

The conjecture becomes:

```text
No positive integer can live forever inside the 2-adic survivor ghost ecology.
```

That is the cleanest target sentence in the repo.

## The "AI-Only" Work Pattern

What AI can do here is not magic proof. It is high-throughput adversarial
transposition:

1. translate every claim into many formalisms;
2. look for the same missing hypothesis across formalisms;
3. generate falsifier families faster than humans would;
4. remember failed routes and prevent name-swapping repeats;
5. keep huge local ledgers synchronized with public prior art;
6. propose theorem targets only after a finite object survives controls.

The forbidden move:

```text
many perspectives -> feeling of inevitability -> proof language
```

The allowed move:

```text
many perspectives -> shared obstruction -> exact target -> falsifier -> checker
```

## Attack Program

### Priority 1: WTF Regression Suite

Build one harness that runs any new invariant against:

```text
Collatz hard records
Mersenne shadows 2^k - 1
low-repeat shadows 2^k q - 5
high-ladder states 2^a q - 1
3n-1 cycle minima {1, 5, 17}
5n+1 divergence-typical starts
negative cycles
phase-collision locks
retimed surplus-1 records
known pseudo-proof archetypes
```

Output: pass/fail plus exact reason. A proof idea is not allowed to graduate
until it survives this harness.

### Priority 2: Sibling Lint

Write a lint layer for proof sketches:

```text
Does the argument use only parity words?
Does it use only frontier density?
Does it survive unchanged under 3n-1?
Does it survive unchanged under a known false sibling?
Where exactly does +1 enter?
```

If the proof cannot answer the last question, it is not Collatz-specific.

### Priority 3: Odd-Unit Lock Miner

Mine repeated phase-collision locks by source spine, target spine, valuation,
and positive-shadow status.

The theorem target:

```text
Repeated regeneration requires cumulative odd-unit locks whose codimension
eventually outruns the number of positive finite shadows.
```

This is not proved. It is the right kind of statement: exact, falsifiable, and
intercept/positivity-sensitive.

### Priority 4: Retimed Lift SMT/SAT Checker

Encode the three-regime retimed-pressure claim at bounded depth with solver
certificates.

The goal is not to solve Collatz. The goal is to turn a messy finite discovery
into replayable proof obligations:

```text
active ladder
post-ladder EOO
low-repeat OO/OOEOO
reserve source before pressure
layer-1 equality cases
```

### Priority 5: Prior-Art Collision Index

Convert Lagarias bibliographies, CCChallenge, recent arXiv, and local atlases
into tagged rows:

```text

known result
known failure wall

```

Every future note gets a collision report before public novelty language.

### Priority 6: Formal Core Roadmap

Formalize small, boring truths first:

The point is trust, not glamour.
