# Originator(s) — Gauss's Class Number Problem for Real Quadratic Fields

_Biography, background, and the ideas that led here._

**Carl Friedrich Gauss (1777–1855)** invented the theory of composition of binary quadratic forms and computed vast tables of class numbers by hand in *Disquisitiones Arithmeticae* (1801). Comparing the rapid decay of $h = 1$ occurrences for negative determinants against their persistent abundance for positive determinants, Gauss conjectured that infinitely many real quadratic fields have class number $1$ — a prediction that remains one of the oldest open problems in algebraic number theory.
