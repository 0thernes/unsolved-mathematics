# Top Mathematicians — Gauss's Class Number Problem for Real Quadratic Fields

_Ten figures who shaped the problem, past and present._

| # | Mathematician | Contribution |
|---|---------------|--------------|
| 1 | Carl Friedrich Gauss | Formulated both imaginary and real class number problems (1801) |
| 2 | Peter Gustav Lejeune Dirichlet | Proved the analytic class number formula linking $h(D)$, $\varepsilon_D$, and $L(1, \chi_D)$ (1839) |
| 3 | Carl Ludwig Siegel | Proved the asymptotic $h(D) \log \varepsilon_D = D^{1/2 + o(1)}$ (1935) |
| 4 | Kurt Heegner | Solved the imaginary $h=1$ problem via modular functions (1952) |
| 5 | Alan Baker & Harold Stark | Independently settled the imaginary $h=1$ problem (1966–1967) |
| 6 | Dorian Goldfeld | Linked effective imaginary class number bounds to rank-3 elliptic curves (1976, 1985) |
| 7 | Benedict Gross & Don Zagier | Proved the height formula completing Goldfeld's effective imaginary solution (1986) |
| 8 | Harold Davenport & Hans Heilbronn | Computed the exact average 3-torsion in quadratic class groups (1971) |
| 9 | Henri Cohen & Hendrik Lenstra | Predicted the exact density $\approx 75.446\%$ of $h(p)=1$ real quadratic fields (1984) |
| 10 | Manjul Bhargava | Extended arithmetic-invariant counting of class groups and discriminants to higher degrees |
