# Attempts — Gauss's Class Number Problem for Real Quadratic Fields

_Notable attempts, near-misses, retracted proofs._

- **Richaud–Degert Families & Yokoi / Chowla Conjectures.** Studying quadratic fields with small regulators ($d = n^2 + 4$, $n^2 + 1$) goes in the *opposite* direction: Biró (2003) proved there are only finitely many (exact classification) of Yokoi's $d = m^2 + 4$ and Chowla's $d = 4m^2 + 1$ with $h(d) = 1$. Small regulators are easy to control precisely because they force $h(d) \to \infty$.
- **Infinitude of Bounded Class Number?** Even the vastly weaker question — are there infinitely many real quadratic fields with $h(d) \le 10^{100}$? — remains completely open!
